# Codex Model Switch 1.6

## 安装与使用

运行 CodexModelSwitch-Setup-1.6.exe，按向导安装。可选择安装目录和桌面快捷方式，开始菜单中也可启动。升级前请关闭旧版切换器。

默认打开独立的“我的平台”页面。每个平台一张卡片，显示名称、主机、模型选择和操作结果，**不显示 Key**。

1. 点击“新增平台”，输入名称，填写 API 地址和该平台的 Key，点击“保存接口”。多个平台独立保存，互不覆盖。
2. 在“平台设置 / 模型”刷新当前平台的模型目录，选择模型并保存。已有模型目录会缓存；卡片也可直接输入模型 ID。
3. 返回“我的平台”，在卡片选择模型，点击“一键验证”或“验证并切换”。验证包括两轮流式工具调用，可能产生服务商费用。
4. 配置切换成功后完整退出并重新打开 Codex，新建任务。程序不会把配置写入成功误报成运行中的会话已经切换。

卡片的“编辑 / 刷新模型”打开平台设置页，可修改地址、Key、模型并保存，也可以重命名。卡片的“删除”只移除这条平台记录，不修改当前 Codex 配置；恢复默认或切换其他平台后，可停止使用原平台。

OpenRouter 是单独的预设，只接受其自己的 Key。普通聚合/中转平台应填写自己的地址和 Key；不能使用别家 Key 登录 OpenRouter。当前仅支持 Responses API、SSE 流式响应及工具调用，不包含 Chat Completions 或 Anthropic Messages 转换代理。

## 数据与分发

安装包和源码包只包含程序、公共模型目录、说明及构建所需文件。**没有预装任何用户平台、API Key、配置备份或日志。** 在没有本地记录的 Windows 用户下，首次启动显示空白平台列表。

在你原来的电脑上仍显示已保存平台，是因为程序读取了本机当前用户的数据，不代表这些记录被打包进程序。平台库保存在：

`%LOCALAPPDATA%/CodexModelSwitch/platforms.bin`

Key 用 Windows DPAPI 加密。平台库、凭据、日志和备份均留在用户数据目录，与程序文件分开。旧版保存的本机接口会迁移到平台库。

**分发给别人只发送安装包或源码包，不要复制整个用户数据目录。** 同一 Windows 用户启动程序会共享该用户的记录。程序不会上传平台库；API 验证和切换后的模型调用会连接你指定的平台。

卸载保留本机平台和凭据，避免破坏 Codex 当前配置和回滚能力。重新安装后本机记录仍可用。

## 回滚与日志

“恢复 Codex 默认”切回内置服务和默认模型选择，保留登录、历史任务和插件设置。
“恢复上次配置”只撤销本工具修改的字段，保留其他后续设置；若同一字段有冲突则停止覆盖。

“操作日志”支持实时查看、复制和导出；日志保存在用户数据目录的 logs 子目录。过滤已输入的 Key、常见令牌和 URL，不保存 API 正文或解密输出。每个会话日志最多三个约 1 MB 文件；窗口显示最近 2000 条。

## 兼容性说明

需要较新版 Codex 支持自定义 Responses 服务和命令式凭据读取。默认读取 CODEX_HOME/config.toml，未设置时读取当前用户 .codex/config.toml。项目级配置、其他 profile、启动参数和组织策略仍可能覆盖默认模型。

API 通用验证通过不等于所有 Codex 专属工具均已验证。真实模型可用性以当前账号和平台响应为准。此程序为独立工具，非 OpenAI 官方产品。
